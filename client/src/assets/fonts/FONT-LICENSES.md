# Bundled Font Licenses — Font Studio / Text Forge

The Font Studio previews text in real display fonts. Google Fonts families
(Orbitron, Audiowide, UnifrakturMaguntia, Pirata One, Press Start 2P, Cinzel,
Share Tech Mono — see `index.html`) are licensed under the **SIL Open Font
License 1.1** and are loaded from Google's CDN at runtime.

The additional display families listed below are **bundled locally** so the
studio works offline. ⚠️ **They are "free for personal use" / demo licenses,
not open-source licenses.** They are provided for personal, non-commercial
use of this tool. If you deploy this app commercially, review each license in
`LICENSES/` and purchase commercial licenses from the foundries where needed:

  - befonts.com, figureestudio.com, koplexs.com, crmrkt.com, creativemarket.com
